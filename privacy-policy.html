Politica de privacidad

Ultima actualizacion: 20 de junio de 2026

MR Splid ayuda a registrar gastos compartidos, pagos y saldos dentro de grupos.

Datos que guarda la app

La app puede guardar estos datos para que sus funciones operen correctamente:

  • Nombre o alias elegido por el usuario.
  • Foto de perfil o foto de grupo, si el usuario decide cargarla.
  • Grupos creados o unidos.
  • Integrantes de cada grupo.
  • Gastos, pagos, participantes, alias de cobro y saldos.
  • Tokens de notificaciones push para avisar cuando se agrega un gasto o pago.
  • Eventos tecnicos basicos de uso, como app abierta, grupo creado, gasto agregado, pago registrado o resumen compartido.

La app no usa estos datos para publicidad ni para seguimiento entre apps o sitios web.

Para que se usan los datos

Los datos se usan para:

  • Mostrar grupos, gastos, pagos y saldos.
  • Sincronizar la informacion entre integrantes.
  • Enviar notificaciones push relacionadas con actividad del grupo.
  • Generar y compartir resumenes.
  • Entender el uso general de la app y mejorar estabilidad y experiencia.

Compartir datos

La informacion de un grupo se comparte con los integrantes de ese grupo. La app usa Firebase, de Google, como proveedor tecnico para base de datos, almacenamiento de fotos y notificaciones.

No vendemos datos personales.

Seguridad

La app usa Firebase Authentication anonimo para identificar instalaciones de la app y reglas de seguridad para evitar acceso publico no autenticado a la base de datos y archivos.

Eliminacion de datos

Si queres eliminar datos de un grupo, podes borrar grupos o movimientos desde la app cuando la funcion este disponible. Para solicitar eliminacion manual de datos, contacta al responsable de la app.
